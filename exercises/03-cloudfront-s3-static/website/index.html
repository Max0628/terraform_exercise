🎯 學習重點

OAC vs OAI

OAC 是新版機制，支援更多功能，包括 SSE-KMS 加密和所有 HTTP 方法。

Bucket Policy

限制只能從特定 CloudFront Distribution 存取，使用 aws:SourceArn 條件。

快取策略

使用 CachingOptimized 政策，靜態內容快取 1 天，大幅降低成本。

HTTPS 強制

viewer_protocol_policy = redirect-to-https 確保所有流量都加密。
